## 💡 Pro Tips

### Mode Selection

- **#PLAN#** → Complex, high-risk, needs strategy
- **#ACTION#** → Clear path, execute quickly
- **#RESEARCH#** → Gather info, no implementation

### Checkpoint Strategy

- **25%** → Early validation, course correction
- **50%** → Major milestone, comprehensive review
- **75%** → Near complete, final adjustments
- **100%** → Quality gates, ready for deployment

### Agent Pairing

- UI work: **ui-ux-developer** + brightness-system-skill
- API work: **ai-sdk-specialist** + aI-agent-implementation-skill
- Bug fixes: Appropriate agent + testing-and-quality-gates-skill
- Deploy: **deployment-engineer** + git-workflow-and-deployment-skill
